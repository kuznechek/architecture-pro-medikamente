# Задание 4. Оценка узких мест при миграции

## Исходная ситуация и цели миграции

### As-Is :

- Один офис, 20 администраторов, 15 врачей

- Данные в Excel и сканах на общем диске

-  Учёт в 1С:Бухгалтерия и 1С:Торговля и склад, ККМ

- Ручной ввод, отсутствие разграничения доступа, нет шифрования, аудита

### To-Be :

- Единый бэкенд-сервис (API) на PostgreSQL (оперативные данные с шифрованием PII)

- CDC (Debezium) → Kafka → Presidio (анонимизация) → ClickHouse (аналитика)

- Keycloak (IAM), MinIO (файлы), Airflow (оркестрация)

- Интеграция с существующими 1С и ККМ

- Рост числа клиентов

## Выявленные проблемы и рекомендации

### Инфраструктура
| Проблема | Рекомендация |
|----------|--------------|
| Низкая пропускная способность сети между филиалами | Доп. каналы, ускорение |
| Нехватка CPU/RAM при увеличивающейся нагрузке | Горизонтальное масштабирование (Kubernetes), автоскейлинг |
| Дисковая подсистема PostgreSQL | Переход на SSD, партиционирование, read-реплики |

### Программное обеспечение

| Проблема | Рекомендация |
|----------|--------------|
| Debezium отстаёт | Увеличить партиции Kafka, настроить batch |
| ClickHouse под частые обновления | Материализованные представления, вставки пачками |
| Бэкенд – единая точка отказа | Реплицирование, балансировщик |

### Интеграция

| Проблема | Рекомендация |
|----------|--------------|
| 1С в файловом режиме | Перевести на серверный режим, синхронизация итогами |
| ККМ → Kafka | Через 1С, буферизация и batch |

### Персонал

| Проблема | Рекомендация |
|----------|--------------|
| Администраторы не обучены | Вебинары, видеоинструкции, супер-пользователь |
| Нехватка DevOps | Найм DevOps или обучения админа |

### Процессы

| Проблема | Рекомендация |
|----------|--------------|
| Нет CI/CD | GitLab CI, автоматизация деплоя |
| Нет плана миграции из Excel | Поэтапная загрузка через API, dry-run |
| Нет мониторинга | Prometheus + Grafana, оповещения |

### Безопасность

| Проблема | Рекомендация |
|----------|--------------|
| Ключи шифрования в коде/env | Hashicorp Vault |
| Нет ротации TLS-сертификатов | cert-manager или cron с Let's Encrypt |
| Нет аудита в ClickHouse | query_log, политики доступа |

**Приоритетные действия :** 

1. Реплики бэкенда и БД
2. План миграции данных из Excel
3. Мониторинг и алертинг
4. Обучение персонала
